## Description

This repository contains a reproducible Python workflow for analysing the
relationship between poverty and mortality using local weighted linear
regression. This was part of assignment 1 for BERN02 - Lund University

## Contents

- `regression_workflow.ipynb` - main analysis and results
- `pollution_cleaneddata.csv` - input dataset
- `requirements.txt` - Python dependencies


## Requirements

Python 3 and the packages listed in `requirements.txt`.
